Что в архиве
------------

Windows (apocalypter-l10n-tools-win-x64.zip):
  patcher.bat   скрипт установки, его и нужно запускать
  patcher.exe   программа, которая вносит перевод в игру
  *.lang        пакеты локализации, например ru.lang

Linux (apocalypter-l10n-tools-linux-x64.tar.gz):
  patcher.sh    скрипт установки, его и нужно запускать
  patcher       программа, которая вносит перевод в игру
  *.lang        пакеты локализации, например ru.lang

Куда класть
-----------

Распакуйте архив в папку игры, где лежат Apocalypter.exe и папка
Apocalypter_Data. Файлы могут лежать прямо рядом с Apocalypter.exe или
в папке из архива внутри папки игры.

Папку игры открывает Steam: правой кнопкой по Apocalypter в библиотеке,
«Управление» → «Просмотреть локальные файлы». На Linux она обычно здесь:
  ~/.local/share/Steam/steamapps/common/Apocalypter

Как запускать
-------------

1. Закройте игру.
2. Запустите скрипт:
   - Windows: дважды щёлкните patcher.bat.
   - Linux: откройте терминал в папке со скриптом и выполните ./patcher.sh
3. Скрипт покажет список пакетов. Введите номер нужного и нажмите Enter.
   Пустой Enter выбирает первый пакет.
4. Дождитесь конца работы и запустите игру.

Windows может предупредить о неизвестной программе («Система Windows
защитила ваш компьютер»). Нажмите «Подробнее» → «Выполнить в любом
случае».

Нужно около 1,5 ГБ свободного места: при первой установке patcher
сохраняет оригинал игры в Apocalypter_Data/data.unity3d.orig.

Сменить язык или переустановить
-------------------------------

Запустите скрипт ещё раз и выберите другой пакет. Patcher всегда берёт
за основу сохранённый оригинал, поэтому переводы не накладываются друг
на друга.

После обновления игры
---------------------

Steam при обновлении игры или проверке целостности файлов записывает
новый data.unity3d без перевода. Тогда patcher завершится с ошибкой
«backup does not match the game bundle». Удалите
Apocalypter_Data/data.unity3d.orig и запустите скрипт снова.

Как вернуть оригинал
--------------------

Удалите Apocalypter_Data/data.unity3d и переименуйте data.unity3d.orig
в data.unity3d. Второй способ: проверьте целостность файлов игры в
Steam, затем удалите data.unity3d.orig.
